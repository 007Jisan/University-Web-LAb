# 🎓 University Web Lab Project

A repository containing foundational web development tasks and assignments completed as part of my university laboratory coursework. This project demonstrates the practical implementation of core web technologies to build structured and styled web pages.

## ✨ Overview
* **Academic Focus:** Developed to fulfill university web lab requirements, focusing on structural markup and visual presentation.
* **Static Web Pages:** Features functional and visually appealing static web layouts using fundamental frontend tools.
* **Media Integration:** Effectively utilizes and structures various image formats (`.jpg`, `.jpeg`, `.webp`) for web display.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3
* **Deployment:** Hosted live via GitHub Pages
